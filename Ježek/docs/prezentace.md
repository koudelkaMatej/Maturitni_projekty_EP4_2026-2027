# Prezentace projektu: Dino Run Apokalypsa

## Problém
Klasický Dino Run z Google Chrome je pouze lokální hra pro jednoho hráče bez jakékoliv perzistence dat, možnosti ukládání výsledků či interakce s okolním světem.

## Naše řešení
Vytvořili jsme síťově propojený ekosystém, kde hra ukládá výsledky do sdílené databáze, web z těchto dat generuje globální žebříčky a přihlášení uživatelé na webu mohou přímo ovlivňovat obtížnost aktivního hráče posíláním pastí.

## Cílová skupina
Hráči retro arkádových her a komunity, které chtějí hrát interaktivně spolu (streamer hraje hru, diváci na webu mu posílají překážky).

## Přínos projektu
Projekt demonstruje čistou synchronní a asynchronní komunikaci desktopové aplikace s relační databází při zachování maximální rychlosti odezvy herní smyčky (60 FPS).
