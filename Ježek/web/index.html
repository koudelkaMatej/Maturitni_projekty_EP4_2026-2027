Dino Run

Vítejte na oficiální stránce maturitního projektu. Hra je moderní dynamickou arkádou inspirovanou klasickým běžícím dinosaurem.

Pravidla hry

  • Hrdina běží automaticky vpřed.
  • Stiskem MEZERNÍKU skáčete přes blížící se překážky.
  • Vyhýbejte se nástrahám a překonávejte vlastní rekordy v délce běhu a dosaženém skóre.

Nastavení kláves

V ovládacím panelu si můžete nastavit vlastní rozložení kláves pro ovládání hry.

O projektu

Tento projekt vznikl jako samostatná maturitní práce propojující herní aplikaci, databázi a přehledné webové rozhraní.
