Flappy Bird

Maturitní projekt: hra v Pythonu s knihovnou Pygame, databáze se skóre hráčů a tento web.

Jak hrát Žebříček

Z čeho se projekt skládá

Hra
Pták, který proletí mezi rourami. Ovládá se mezerníkem nebo šipkou nahoru.
Databáze
Ukládá uživatele a skóre z každé odehrané hry.
Web
Popis hry, žebříček nejlepších hráčů a přihlášení.

Školní maturitní projekt, 4. ročník.
