O hře

Cílem je dostat ptáka co nejdál. Pták neustále padá a každé mávnutí ho vymrští nahoru. Když narazíš do roury nebo do země, hra končí.

Ovládání

KlávesaCo udělá
MezerníkPták mávne křídly a vyletí nahoru
Šipka nahoruTotéž co mezerník

Jak hru spustit

Potřebuješ Python 3 a knihovnu Pygame. V terminálu ve složce Flappy-bird spusť:

pip install pygame
python flappy.py

Školní maturitní projekt, 4. ročník.

Základ hry: Leonardo Marques (původní projekt na GitHubu). Vlastní úpravy a rozšíření: doplň své jméno.
